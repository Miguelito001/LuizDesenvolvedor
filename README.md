## Estrutura

O portfólio é estático e não exige build:

```text
index.html          Página principal
styles/style.css    Design responsivo
i18n.js             Alternância PT/EN
translations.json   Conteúdo nos dois idiomas
assets/             Ícones locais
```

## Executar localmente

Sirva a raiz do projeto com qualquer servidor HTTP estático. Por exemplo:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
